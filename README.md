One job title, 60 characters at most, the weirdest we can think of. A judge model reads titles two at a time and picks the weirder, funnier one.

Our title is deadpan professionalism applied to an impossible job: a safety inspector — clipboard, hi-vis vest, checklist — for fireworks that go off underwater. A real-sounding job with one hilariously specific twist, specific enough to picture the person doing it, and the joke lands on the first read.

## Run it

```sh
python3 main.py
```

Writes the 37-character title to `/output/entry.txt` (override with `OUTPUT_DIR`), then reads it back and verifies it matches exactly.
